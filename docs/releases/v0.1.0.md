# golayout v0.1.0

Initial release of the shared Go source layout and license-header tooling.

- Add `pkg/format` for deterministic structural layout followed by pinned gofumpt v0.12.0.
- Add `pkg/header` for template-based source notices that preserve generated markers, build constraints and package documentation.
- Provide a read-only CLI with explicit write mode, input preflight and atomic per-file replacement.
- Share repository scripts for formatting and header checks with explicit file ownership and exclusions.
- Include bilingual documentation, Go quality gates and release-driven GitHub Pages deployment.

Requires Go 1.27.0 or newer. This pre-v1 release may introduce intentional API or formatting-policy changes in future versions.

Install the CLI:

```sh
go install github.com/longxi-go/golayout/cmd/golayout@v0.1.0
```

Use the library:

```sh
go get github.com/longxi-go/golayout@v0.1.0
```
